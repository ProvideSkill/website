# Company Website

Landing pages, course info pages, and marketing site.

## Structure
- `/pages` — Next.js pages (or HTML files if static)
- `/public` — images, assets
- `/components` — reusable UI components

## Tech Stack
- Next.js + Tailwind CSS (or plain HTML + Bootstrap)
- Deployed on: Vercel or GitHub Pages

## Setup
```bash
npm install
npm run dev
```

Open http://localhost:3000
